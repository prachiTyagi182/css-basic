# 🎨 CSS Basics Practice

A collection of beginner-friendly HTML and CSS files covering fundamental styling concepts, selectors, and layout properties.

## 📁 Files Included

* **`box_model.html`** – Demonstrates CSS Box Model (margin, border, padding, content).
* **`color.html`** – Examples of CSS color properties and styling.
* **`csstype.html`** – Covers inline, internal, and external CSS implementation.
* **`id_selector.html`** – Usage of CSS ID selectors for targeting specific elements.
* **`index.html` & `mystyle.css`** – Main HTML page linked with an external stylesheet.
